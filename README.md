# CMSC131 Grade Tracker

I wanted a quick way to answer one question: what do I need on the final to finish with an 80%? This tracker uses the course weights to answer that as grades come in.

- Enter points for quizzes, projects, midterms, and the final.
- Mark posted scores **Confirmed** and what-if scores **Estimate**.
- Pick a course target to see the average you need on unentered work or the score you need on the final.

The tracker starts with a blank gradebook. Entries save in the current browser.

## Run locally

From this folder, run `python3 -m http.server 8000` and open `http://localhost:8000`.

## GitHub Pages

Upload the files in this folder to the repository root. In **Settings → Pages**, choose **Deploy from a branch**, **main**, and **/(root)**, then save.
